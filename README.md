# Smart Meney Trading (SMC)
Este robot de trading esta basado en Smart Money Trading (Concepto de dinero inteligente).

## SMC
En esta carpeta se encuentra el codigo de cómo el robot detecta invalances, puntos de interes, estructura y demas.

### Identificar
1. Buscar direccionalidad en H4 o 1D
2. Marcar el Order Block
3. Bajar de temporalidad a H1 o M15


### Anotaciones
- Si el precio mitiga menos del 50% de un bloque con mecha es probable que haya una ineficiencia en una temporalidad menor.
